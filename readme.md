## 🆕 Что нового в v3

- **Модульная архитектура** (ESM): service worker, парсер страницы и popup разделены.
- **Вкладки в popup**: «Активные» и «История» с поиском и фильтрами.
- **Пакетная загрузка** альбома/плейлиста/артиста во второй колонке; выбор диапазона
  «С/По» (для коллекций >1000 треков — точные числовые поля, по умолчанию всё).
- **История загрузок** в IndexedDB: обложка, трек, артист, дата, статус, повтор/удаление.
- **Докачка** через HTTP `Range`: частичные чанки хранятся в IndexedDB и переживают обрыв сети/перезапуск.
- **Умная очередь**: exponential backoff, пауза/продолжение, повтор без повторного парсинга плейлиста.
- **Оптимизированные ID3-теги**: обложка с ресайзом, кириллица, TRCK/TALB/TYER/TPE1/TCON.
- Тяжёлая работа (сеть, теги, сборка файла) выполняется в service worker, а не в popup.

## 🚀 Автоустановка в Chromium-браузеры (Windows)

В папке расширения лежит `autoinstall.cmd` — запустите его двойным щелчком
(права администратора не нужны). Скрипт сам находит установленные браузеры и
предлагает установить расширение.

Что он делает:

- использует как папку расширения **ту папку, из которой запущен `autoinstall.cmd`**
  (ничего не копирует, папку можно перемещать только вместе со скриптом);
- принудительно закрывает запущенные браузеры, чтобы настройки применились;
- включает **режим разработчика** в профилях браузеров (правит
  `extensions.ui.developer_mode` в `Preferences`);
- создаёт ярлыки **Yandex Music Fisher - <Браузер>** на рабочем столе и в меню «Пуск»;
- в поддерживаемых браузерах ярлык запускает браузер с
  `--load-extension=<папка>` — расширение подключается автоматически;
- для **Chrome 137+** и **Arc** открывает страницу расширений и папку с файлами —
  останется нажать «Загрузить распакованное расширение» (режим разработчика уже
  включён, путь к папке в буфере обмена).

| Браузеры | Способ |
|---|---|
| Microsoft Edge, Яндекс Браузер, Opera, Opera GX, Brave, Vivaldi, Ungoogled Chromium, Chromium-Gost, Ghost Browser, SRWare Iron, Cent Browser, Thorium | ярлык с автозагрузкой |
| Google Chrome 137+ | вручную через `chrome://extensions/` |
| Arc | вручную, `arc://extensions/` |
| Samsung Internet | версии для Windows нет |

> ⚠️ Перед запуском ярлыка браузер должен быть **полностью закрыт**, иначе он
> проигнорирует параметр загрузки расширения. Если браузер уже запущен обычным
> способом, закройте все его окна и запустите ярлык.
>
> 💡 Для постоянной установки (без ярлыка) используйте ручной режим
> «Загрузить распакованное» — расширение сохранится в профиле браузера.

Обновление версии: запустите `autoinstall.cmd` снова, затем нажмите «Обновить»
на странице расширений браузера. Удаление ярлыков: `autoinstall.cmd` → пункт `[U]`
(папку с расширением скрипт не трогает).

## 🧩 Установка распакованного расширения в Chrome / Opera / Edge

### 📥 Шаг 1: Скачивание репозитория

1. Перейдите по ссылке: [Скачать ZIP](https://github.com/vectorserver/yandex_music_fisher_mod/archive/refs/heads/master.zip)
2. Распакуйте архив в удобное место, например: `C:\yandex_music_fisher_mod-master\`

---

### 📁 Шаг 2: Папка с расширением

Перейдите в папку: `C:\yandex_music_fisher_mod-master\` — именно она будет устанавливаться в браузер.

Убедитесь, что внутри есть:
- `manifest.json`
- другие .js и .html файлы

---

### 🌐 Шаг 3: Открой страницу расширений

- **Chrome** → `chrome://extensions/`
- **Opera** → `opera://extensions/`
- **Edge** → `edge://extensions/`

---

### ⚙️ Шаг 4: Включи режим разработчика

- Включи переключатель **Режим разработчика** (вверху или внизу страницы).

---

### 📂 Шаг 5: Установка

1. Нажми кнопку **Загрузить распакованное расширение**
2. Выбери папку `C:\yandex_music_fisher_mod-master\`
3. Подтверди выбор папки

---

### ✅ Шаг 6: Проверка

- Убедись, что расширение включено
- Если есть ошибки:
  - Проверь путь: все файлы должны быть внутри `C:\yandex_music_fisher_mod-master\`
  - Убедись, что браузер поддерживает `manifest_version: 3`

---

### 🎉 Шаг 7: Готово!

Расширение установлено. Иконка появится в панели браузера.

---

## 🦊 Установка в Firefox

1. Перейди: `about:debugging#/runtime/this-firefox`
2. Нажми 👉 **Загрузить временное дополнение...**
3. Укажи файл `manifest_Firefox.json` внутри папки `C:\yandex_music_fisher_mod-master\` если не помогло удали `manifest.json` только оставь `manifest_Firefox.json`
4. Расширение активируется до перезапуска Firefox

> ⚠️ Firefox поддерживает только временную установку без подписи. После перезапуска расширение будет отключено.
